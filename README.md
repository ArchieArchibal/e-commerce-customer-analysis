# e-commerce-customer-analysis
📊 Online Retail Customer Analysis (RFM)
Project Goal: Clean transaction data and segment customers to improve marketing efficiency.

Key Steps:

Handled missing data (CustomerID) and cleared anomalies (negative quantities/prices).

Created a revenue metric and analyzed sales trends by country and month.

Performed RFM Analysis (Recency, Frequency, Monetary) to segment 4000+ customers.

Results:

Identified Potential Loyalists as the largest segment (1500+ users).

Discovered that UK accounts for ~90% of revenue.

Recommended retention strategies for the "At Risk" and "Hibernating" segments.

Tools: Python (Pandas, Matplotlib, Datetime).
